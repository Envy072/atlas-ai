# Archive

This folder contains historical engineering reviews and repository
snapshots, preserved unchanged for historical reference.

Documents here describe the repository as it existed at a specific
past point in time. They should **not** be treated as the current
state of the repository — several of their findings have since been
resolved or superseded by later work.

Current engineering direction and active planning documents remain in
the repository root (`CLAUDE.md`, `ATLAS_AI_V2_ROADMAP.md`, and the
platform/design docs).
